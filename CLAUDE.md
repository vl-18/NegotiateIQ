# Coding Instructions

Follow these rules every time you write code in this project.

## 1. Keep It Simple
- Do not overcomplicate the code.
- Always prefer the simplest solution that works.
- Avoid unnecessary abstractions, layers, or dependencies.

## 2. Best Practices & Readability
- Follow best coding practices for the language in use.
- Include small, clear comments to explain *why*, not just *what*.
- Use meaningful variable and function names.
- Keep functions short and focused on a single task.

## 3. Plan Before You Code
- Always outline a plan before writing any code.
- State the approach, files to be created/modified, and key decisions.
- Get confirmation if the plan involves significant changes.

## 4. Report Bugs/Errors Before Fixing
- If a bug or error is found, report it clearly first.
- Describe what is wrong, where it is, and why it happens.
- Only proceed to fix after reporting.

## 5. Maintain a Build Log
- Keep `build_log.md` updated at all times.
- Log what has been done and what is still pending.
- Add a timestamp or commit reference where relevant.
